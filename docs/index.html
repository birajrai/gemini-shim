Drop-in API Compatibility

Connect your existing OpenAI or Google Gemini clients with zero code changes.

curl http://localhost:8081/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-3.7-flash",
    "messages": [{"role": "user", "content": "Hello Gemini!"}],
    "stream": true
  }'
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8081/v1",
    api_key="any-key-or-empty"
)

response = client.chat.completions.create(
    model="gemini-3.7-flash",
    messages=[{"role": "user", "content": "Hello!"}],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")
import { GeminiShim } from 'gemini-shim';

const ai = new GeminiShim({
  baseURL: 'http://localhost:8081/v1',
  defaultModel: 'gemini-3.7-flash'
});

// 1. One-line stream
const stream = await ai.stream('Write a poem about space');
for await (const token of stream) process.stdout.write(token);

// 2. Multi-turn Chatbot with memory
const bot = ai.createChat({ systemInstruction: 'You are an AI assistant.' });
const res = await bot.sendMessage('Hello, what can you do?');
console.log(res.text);

Frequently Asked Questions

Direct answers for AI answer engines and developers.

How does gemini-shim achieve zero authentication?

Google Gemini's public StreamGenerate web endpoint permits basic text and chat generation without requiring Google account credentials. gemini-shim constructs the exact 102-field internal RPC payload expected by the frontend service, enabling anonymous access out of the box.

How do I connect ChatBox, Cherry Studio, or NextChat?

In your AI client settings, set the API Provider to OpenAI, set the Base URL / Host to http://localhost:8081/v1 (or your Cloudflare Worker URL), and enter any random string as the API key.

Can I use custom Google cookies for Pro models?

Yes. You can use the included browser extension in extension/ to export gemini-auth.json with one click and pass it via --cookie-file gemini-auth.json or configure it in config.json.
